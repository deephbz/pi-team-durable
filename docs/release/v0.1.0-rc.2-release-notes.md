# Pi Team Durable 0.1.0-rc.2: performance

Incremental graph controller, indexed storage and lazy validators. Same Team
semantics as 0.1.0-rc.1: 3,000 differential seeds match the port. At 200
Tasks it runs 29x faster with a 29x smaller SQLite file. At 500 Tasks the port
exhausts its heap, and this version finishes in 86 s. At 50 Tasks the heap is
1.76x larger. This is a prerelease on npm `next`.

## Before deploy

The first open migrates the store to the indexed format. The migration is
one-way; rollback means restoring a backup. Back up the store, and stop every
older node process first.

## Known issues

1. An Alert is lost when the recipient's model errors. It shows as
   unanswered. Pi Team Bright retries it; this package does not.
2. `team_sync` can replay pages that an earlier call released. Act only on
   `task_read`, and never call `team_sync` from a nested tool call.
3. Interrupt: a Worker can interrupt the lead, the run to stop is chosen when
   the Alert is accepted, and the abort has no settle bound.
4. An Alert can be admitted after its recipient is closed or fenced. After an
   owner Close, a busy Worker can still run one tool call.
