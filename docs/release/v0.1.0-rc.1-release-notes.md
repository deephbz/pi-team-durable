# Pi Team Durable 0.1.0-rc.1: port

Pi Team Bright rc.7 Team semantics on pi-durable. This is a prerelease on npm
`next`. It needs a host that supplies the Team ports; today that host is the
AmPi node. The source is HyperCarrier (private) at the certified port, renamed
from `durable-team`. The persisted notice value `sender: 'durable-team'` is a
protocol value and stays unchanged.

The first version of this package was published by hand, so it has no npm
provenance. Later versions publish from CI with provenance.

## Known issues

1. An Alert is lost when the recipient's model errors. It shows as
   unanswered. Pi Team Bright retries it; this package does not.
2. `team_sync` can replay pages that an earlier call released. Act only on
   `task_read`, and never call `team_sync` from a nested tool call.
3. Interrupt: a Worker can interrupt the lead, the run to stop is chosen when
   the Alert is accepted, and the abort has no settle bound.
4. An Alert can be admitted after its recipient is closed or fenced. After an
   owner Close, a busy Worker can still run one tool call.
