# Pi Team Durable 0.1.0-rc.5: pi-durable 1.6.0

Needs `@earendil-works/pi-durable` 1.6.0 and its family (`chord`, `pi-ai` 1.6.0), pinned exactly as peers. The
Team authority, notices, receipts and the API of this package are unchanged. This is a prerelease on npm `next`.

## Before deploy

pi-durable 1.6.0 upgrades the store schema on first open (`pi.tool` v4, `pi.generation` v3). Older nodes cannot read
it. Snapshot stores and stop every older node process first.
